# 🚀 How to put this on your GitHub profile

## 1. The magic repo

Your profile is powered by the public repo named **exactly** your username:

```
MohammedQuraan24/MohammedQuraan24
```

GitHub shows that repo's `README.md` at the top of your profile page. ✨

## 2. Files in the repo

| File | What it is |
| :--- | :--- |
| `README.md` | Your profile content |
| `assets/banner.svg` | Animated header banner |
| `assets/divider.svg` | Small glowing divider |

## 3. Push changes

From Git Bash:

```bash
cd ~/github-profile
git add .
git commit -m "update profile"
git push
```

Then refresh https://github.com/MohammedQuraan24 (Ctrl+F5 if it looks cached).
